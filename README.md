# Business Analytics Portfolio

## Alec J. Thomas

This portfolio presents applied statistical analysis and quantitative decision-making work developed through graduate-level business analytics coursework. The focus is not simply on calculating an answer, but on selecting the correct method, interpreting the result, and translating statistical output into a decision-relevant conclusion.

### Core analytical areas

- Probability and normal distributions
- Sampling distributions and standard error
- Binomial probability
- Confidence intervals for means
- Confidence intervals for proportions
- Margin of error
- Sample-size determination
- Statistical method selection and interpretation

## Selected examples

| Analysis | Method | Result |
|---|---|---|
| Soft-drink probability | Normal distribution | `P(X > 13) = 0.9466` |
| Ball-bearing tolerance | Normal distribution | `P(X > 0.77) = 0.0668` |
| LED defect count | Binomial distribution | `P(X = 1) = 0.3851` |
| Sample-mean probability | Sampling distribution | `P(X̄ < 49) = 0.1056` |
| Mean confidence interval | t interval | `1175.09 – 1224.91` |
| Proportion confidence interval | z interval | `0.3007 – 0.3303` |
| Required sample size: mean | z-based planning | `n = 250` |
| Required sample size: proportion | z-based planning | `n = 385` |
